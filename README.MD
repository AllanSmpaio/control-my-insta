# control-my-insta 🔍

Ferramenta em Python para analisar dados exportados do Instagram e identificar contas que você segue, mas que não te seguem de volta.

## 🚀 Como Usar
1. Coloque os arquivos `followers_1.html` e `following.html` na raiz do projeto.
2. Instale a dependência: `pip install -r requirements.txt`
3. Execute o script: `python main.py`

## 🛠️ Tecnologias
- Python 3
- Beautiful Soup 4
